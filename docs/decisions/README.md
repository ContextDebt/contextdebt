# Decisions

One file per decision that shapes how this repo is built: `YYYY-MM-DD-<topic>.md`.
Read this folder before making any judgment call that touches the bigger picture.
If you hit a fork no file here covers, stop and ask — do not guess.

Each file:
- **Decision** — what, and the real reason why
- **Rejected alternatives** — and why each was rejected
- **Constraints** — must / must not
- **Judgment rules** — how to choose in cases not covered
- **Open questions**
